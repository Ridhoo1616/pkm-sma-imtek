5. Menyiapkan basis data

Cukup membuat basis data dan penggunanya. Tabel dan data awal dibuat otomatis oleh backend saat pertama kali menyala. Jalankan psql -U postgres, lalu:

CREATE ROLE ppdb LOGIN PASSWORD 'ganti-dengan-sandi-anda';
CREATE DATABASE sma_imtek OWNER ppdb ENCODING 'UTF8';

6. Menjalankan backend (terminal 1)

cd backend
cp .env.example .env        # Windows: copy .env.example .env

Buka backend/.env, lalu isi minimal:

DB_USER=ppdb
DB_PASS=ganti-dengan-sandi-anda
DB_NAME=sma_imtek
JWT_SECRET=isi-acak-panjang       # contoh: openssl rand -base64 48
CORS_ORIGINS=http://localhost:3000,http://127.0.0.1:3000

Kemudian jalankan:

go run .

Berhasil bila muncul server berjalan di :8090. Periksa di peramban: localhost:8090/api/sehat menjawab {"status":"baik"}.

7. Menjalankan panel admin (terminal 2)

cd frontend
npm install
echo NEXT_PUBLIC_API_URL=http://localhost:8090 > .env.local   # Windows: pakai Notepad
npm run build
npm run start -- -p 3001

npm install di folder ini wajib dikerjakan lebih dulu, karena situs Astro di langkah berikutnya ikut memakai kode dan pustaka dari folder frontend.

8. Menjalankan situs sekolah (terminal 3)

cd web
npm install
npm run build

Lalu nyalakan dengan alamat backend dan panel admin.

macOS / Linux:

HOST=localhost PORT=3000 NEXT_PUBLIC_API_URL=http://localhost:8090 \
SITUS_LAMA=http://localhost:3001 SITUS_LAMA_DITERUSKAN=ya npm run start

Windows (PowerShell):

$env:HOST="localhost"; $env:PORT="3000"; $env:NEXT_PUBLIC_API_URL="http://localhost:8090"
$env:SITUS_LAMA="http://localhost:3001"; $env:SITUS_LAMA_DITERUSKAN="ya"; npm run start
Sudah jalan. Buka http://localhost:3000 untuk situs sekolah dan http://localhost:3000/admin untuk panel panitia.
Akun bawaan: admin / admin123.
Wajib: segera ganti sandi admin lewat menu Ganti Sandi. Hash sandi bawaan ada di repositori publik, jadi siapa pun yang tahu alamat panel dapat masuk selama sandinya belum diganti.

Untuk pengembangan (kode berubah langsung terlihat)

Ganti npm run build + npm run start dengan mode dev:

cd frontend && npm run dev -- -p 3001
cd web && npm run dev                  # http://localhost:4321

Pada mode dev, Astro di porta 4321 dan /admin dialihkan ke localhost:3001/admin. Tambahkan http://localhost:3001 ke CORS_ORIGINS di backend/.env, lalu nyalakan ulang backend.

9. Menyiapkan tes seleksi dengan 40 soal latihan

Berkas frontend/public/templat/latihan-soal-40.csv berisi 40 soal pilihan ganda setara SMP, lengkap dengan kunci dan pembahasan. Kunci jawabannya tersebar merata (A sampai E masing-masing 8).

Mata pelajaranJumlah soal
Matematika12
Bahasa Indonesia8
Bahasa Inggris8
IPA8
IPS4
Jumlah40
  1. Impor soal. Panel → Bank Soal → Impor dari Excel. Tautan 40 soal latihan tes di jendela itu mengunduh berkasnya. Pilih berkasnya, lalu kirim. Satu baris yang salah membuat seluruh impor ditolak, dan pesannya menyebutkan nomor barisnya.
  2. Buat paket ujian. Panel → Tes Seleksi → Tambah Paket Ujian. Isi nama, tahun ajaran, nilai minimum, lama pengerjaan (saran: 60 menit), serta jadwal dibuka dan ditutup. Pada Komposisi per mata pelajaran isi 12 / 8 / 8 / 8 / 4 seperti tabel di atas.
  3. Aktifkan paket, lalu pada menu Pengaturan setel ujian_aktif menjadi 1.
  4. Peserta mengerjakan lewat halaman Cek Status setelah berkas pendaftarannya diverifikasi panitia.

Hal yang perlu diketahui: waktu dihitung server (memuat ulang halaman tidak menambah waktu), jawaban tersimpan satu per satu, soal diacak di dalam kelompok mata pelajarannya, kunci jawaban tidak pernah dikirim ke peramban peserta, dan hasilnya dapat dilihat per mata pelajaran.

10. Bila ada masalah

GejalaPenyebab yang paling sering
basis data tidak merespons saat backend menyalaPostgreSQL belum jalan, atau DB_USER/DB_PASS/DB_NAME di .env salah
SSL is not enabled on the serverSetel DB_SSLMODE=disable di backend/.env
Halaman tampil, tetapi data kosongBackend mati, atau NEXT_PUBLIC_API_URL salah
Formulir gagal: "tidak dapat menghubungi server"Alamat situs belum ada di CORS_ORIGINS. localhost dan 127.0.0.1 dihitung berbeda
/admin tidak terbukaPanel Next (porta 3001) belum menyala, atau SITUS_LAMA tidak menunjuk ke sana
port already in useProgram lama masih berjalan. Tutup terminalnya, atau hentikan prosesnya
JWT_SECRET wajib diisiIsi JWT_SECRET dengan nilai acak
